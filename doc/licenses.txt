MAGIC LANTERN WORKBENCH PLATFORM - LICENSES
Version 1.0.0 - 2026-10-09

This document lists the licenses that apply to the Magic Lantern Workbench
Platform (MLW) and to the third-party software it contains, is built with, or
runs on. It was compiled from the license files and package metadata of the
dependencies at the versions used in release 1.0.0 (go.mod, package-lock.json
and the Docker Compose files). It is an inventory, not legal advice. Check the
license texts of the exact versions you redistribute.

- The MLW source code is released under the MIT License (Wizzer Works).

  distributed with the project and their licenses do not apply to it.

5. CONTAINER IMAGES
--------------------------------------------------------------------------

The Compose files and the Dockerfile pull these images from public
registries. The images are not part of this repository. Each image contains
software under its own licenses, which you can inspect in the image (for
example under /usr/share/doc, where the image has it).

Services (docker-compose*.yml)

  cassandra:5.0                       Apache Cassandra: Apache-2.0
  quay.io/keycloak/keycloak:26.4.0    Keycloak: Apache-2.0
  postgres:16                         PostgreSQL: PostgreSQL License (a
                                      permissive license similar to
                                      BSD/MIT). Used by Keycloak in the
                                      production override.

Application image (app/Dockerfile)

  node:22-alpine         build stage only (web UI): Node.js is MIT; Alpine
                         Linux packages have various licenses.
  golang:1.25-alpine     build stage only (Go binary): Go is BSD-3-Clause.
  gcr.io/distroless/static-debian12:nonroot
                         runtime image: Distroless is Apache-2.0. The image
                         holds only the application binary plus a minimal set
                         of Debian files (CA certificates, timezone data,
                         base files). The Mozilla CA certificate bundle is
                         under the Mozilla Public License 2.0, and the time
                         zone database is in the public domain.

The final application image therefore contains the MLW application (MIT)
with the Go and web components of sections 3 and 4, and the distroless base.
